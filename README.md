# yuragi-font

**yuragi** = trembling/variance in Japanese

手書き風フォントシステムの技術検証デモ

## コンセプト

デジタルフォントの「同じ文字は同じ形」という特性を崩し、手書きのような揺らぎを再現します。同じ文字が文章内で異なる見た目になることで、温もりのある表現を目指しています。

## デモページ

GitHub Pagesで公開予定: `https://sashi7446.github.io/yuragi-font/`

## 使い方

1. テキストエリアに文字を入力
2. **Enterキー**を押して確定
3. 各文字にランダムでフォントバリエーションが割り当てられます
4. 同じ文字でも異なるフォントで表示されます

### 例

「**ワクワクする**」と入力すると:
- 1文字目の「ワ」→ バリエーション3（丸ゴシック）
- 2文字目の「ク」→ バリエーション1（ゴシック体）
- 3文字目の「ワ」→ バリエーション2（明朝体）
- 4文字目の「ク」→ バリエーション5（セリフ体）

のように、同じ「ワ」「ク」でも異なるフォントで表示されます。

## 技術仕様

### MVP実装（現バージョン）

- **HTML/CSS/JavaScript**のシンプルな構成
- **6種類のフォントバリエーション**:
  1. Noto Sans JP（ゴシック体）
  2. Noto Serif JP（明朝体）
  3. M PLUS Rounded 1c（丸ゴシック）
  4. Arial（サンセリフ）
  5. Georgia（セリフ）
  6. Trebuchet MS（サンセリフ）

### 主な機能

- ✅ 入力確定時に各文字へランダムでバリエーション割り当て
- ✅ 一度割り当てられたバリエーションは固定
- ✅ Unicode文字に対応
- ✅ レスポンシブデザイン
